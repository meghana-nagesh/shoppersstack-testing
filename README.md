# ShoppersStack Testing
Manual and automation testing of the ShoppersStack e-commerce web application.

## What's covered
- 40+ manual test cases across Shopper, Merchant and Admin modules (Functional, Integration, System)
- 28 automated tests using Selenium WebDriver, Java, TestNG and Page Object Model
- Test Plan, RTM, Defect Report and Test Execution Summary

## Folders
- SS_Manual/ : manual test cases and test documents
- SS_Automation/ : Selenium automation project (see its README for how to run)

## Tools
Selenium WebDriver, Java, TestNG, Maven
